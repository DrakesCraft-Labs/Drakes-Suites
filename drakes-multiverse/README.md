## ⚙️ Configuración Modular (`modules/*.yml`)
Configuración desacoplada en `plugins/DrakesMultiverse/modules/`:
* `multiverse_nets.yml`: Configuración de nodos de red, canales de almacenamiento y recetas.
* `multiverse_creatures.yml`: Spawns, habilidades de entidades y recompensas de combate.

Recarga en caliente:
```
/drakessuites reload drakes-multiverse [modulo]
```
